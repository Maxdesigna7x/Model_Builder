Pooling reduce posiciones dentro de cada canal

Max y promedio: misma ventana, distinta pregunta

Cada ventana local produce una posición de salida por canal: Max conserva el valor mayor; Avg calcula la media. El tamaño del paso determina cuánto se solapan las ventanas.

Global AvgPool: una media por mapa

adaptiveavgpool1dadaptiveavgpool2d

Resume la extensión temporal o espacial completa de cada canal. Con output_size = 1 entrega un valor por mapa; con otro tamaño, divide la extensión en regiones adaptativas.

Diferencia clave: pooling local reduce gradualmente; el global colapsa toda la extensión en una sola representación por canal.

Las formas y los ejes también cuentan

Separa cambios de representación de cambios de contenido. Un diagrama futuro debe mostrar las etiquetas de ejes y conservar el orden de valores.

Unir ramas: sumar o concatenar

addconcat

Útil para hacer visibles las conexiones residuales y los atajos de U-Net. Add exige formas compatibles; Concat conserva el contenido de ambas ramas en el eje elegido.

Softmax redistribuye un grupo

softmax

A diferencia de una activación independiente, Softmax relaciona los valores del eje configurado para formar una distribución.

Capas y regularización transformar valores, mantener o reducir información

Dense conecta características con salidas

linear

Una capa lineal mezcla las características del último eje. En una secuencia puede aplicar la misma proyección a cada paso sin combinar pasos de tiempo.

Normalizar o apagar durante el entrenamiento

Normalización · valores y forma
batchnorm1dbatchnorm2dlayernorm
Dropout · máscara en entrenamiento
dropoutdropout2d

BatchNorm 1D/2D normaliza por canal con estadísticas del lote; LayerNorm normaliza el último eje por muestra/token. Dropout regulariza durante entrenamiento y no aplica máscara aleatoria en evaluación.

Secuencias y atención recurrencia, resúmenes y relaciones entre posiciones

RNN, GRU y LSTM pasan estado entre pasos

rnngrulstm

Cada paso recibe una observación y el estado anterior. El flujo muestra el mecanismo recurrente; las compuertas internas de GRU/LSTM se dejan como esquema conceptual.

Resumir o seleccionar posiciones de una secuencia

El modo del nodo define cómo se obtiene un vector resumen. TemporalSelect representa la extracción del estado final válido cuando las secuencias tienen longitudes distintas.
